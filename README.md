We are developing a machine learning-based women safety analytics system focused on India. The system will use historical NCRB crime data, particularly district-wise crimes against women such as rape, kidnapping and abduction, assault, and other related crimes, along with geographical information about Indian districts and popular locations.
The main objective is to analyze where and when reported crimes against women are concentrated. Machine learning techniques such as clustering and anomaly detection will be used to identify crime hotspots and unusual patterns across different districts and time periods.
The results will be presented through an interactive map and dashboard. A user can select a city or district and view its historical crime statistics, crime categories, trends over time, and areas with higher concentrations of reported incidents. Popular places can also be displayed on the map to provide geographical context.
For example, if a user selects Gurugram, the system could display the district's historical reported cases of rape, kidnapping, assault, etc., show how these numbers have changed over the years, and visualize areas with higher concentrations of reported incidents.
The system is intended as a data-driven awareness and decision-support tool. It does not claim that a particular location is inherently safe or unsafe; instead, it helps users understand historical crime patterns and make informed decisions based on available data.
